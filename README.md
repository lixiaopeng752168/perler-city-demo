# 豆迹 · 拼豆门店采集面板

通过 Chrome 扩展在本机操作百度地图，按城市等级或指定城市搜索并读取真实候选门店。支持翻页、UID/名称地址去重、排除词、暂停继续、任务日志、人工核验和 CSV 导出。

- 在线面板：https://lixiaopeng752168.github.io/perler-city-demo/
- 下载扩展：网页“接入与设置”，下载采集助手.zip，解压后加载 extension 文件夹。
- 本机面板：安装后点击 Chrome 扩展图标打开，面板自身无需联网。
- 使用说明：[使用说明.md](使用说明.md)

不含演示门店或模拟任务。没有安装扩展时不会发起采集。任务与结果存储在本机，数据不上传 GitHub。

已验证实际页面字段解析与第二页操作，任务执行器有本机测试。首次完整自动任务仍需在安装扩展后的 Chrome 中验收。
